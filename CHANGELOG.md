# Changelog

## 0.1.0 (first release)
- Connect over WebHID (desktop Chrome or Edge) to an MCHOSE Ace 75 8K.
- Sensitivity: press point, Rapid Trigger and dead zones per key, with presets.
- Remap on the Windows, Windows + Fn, Mac and Mac + Fn layers.
- Lighting: backlight effects, logo light, ambient light, and per-key custom colors ("Custom" effect).
- Settings: reporting speed, Rapid Trigger smoothing, double-press filter, Windows-key lock, sleep time.
- Profiles: view all three onboard profiles; switch which one the keyboard uses.
- Automatic backup file before the first change; Restore; every write is read back and compared.
- A keyboard the app does not know yet is never read or written; it can produce a shareable report.
